🗺️ 4. User Journey — Typical Shopping Flow

The following is the expected flow for a user browsing and purchasing from Lagos Luxe:

  1. Landing on the Website
    The user sees the announcement bar (free delivery offer), then the sticky navigation. The hero section immediately communicates the brand: "Dress to Command Attention" with CTAs to Shop Now or learn more.
  2. Browsing Categories
    User scrolls to the Categories section and sees 4 category cards (Men's, Women's, Accessories, Premium). Clicking any category scrolls to the product grid for browsing.
  3. Exploring Products
    User browses the 8-product Best Sellers grid. Each card shows: category label, product name, short description, price (and original price for sale items), wishlist button, and badge (New/Sale/Premium).
  4. Adding to Wishlist
    User clicks the 🤍 heart icon on any product. It toggles to ❤️ and a toast notification confirms the action. The wishlist is session-only (in-memory).
  5. Adding Items to Cart
    User clicks "+ Add" on a product card. The button briefly shows "✓ Added" in green. The cart sidebar slides open from the right automatically. The cart badge in the navbar increments and briefly animates.
  6. Managing the Cart
    In the cart sidebar, user can: increase/decrease quantities using + / − buttons, remove items with the ✕ button, and see the running total in Naira at the bottom.
  7. Checkout
    User clicks "Proceed to Checkout →". The cart closes, a toast notification confirms the order was placed with the total amount, and the cart resets to empty. (Checkout is simulated — no actual payment in this prototype.)
  8. Newsletter Sign-up
    User enters email in the newsletter section and clicks Subscribe. Email is validated by the browser. On success, a toast confirms the subscription and the form clears.
  9. Finding the Store
    User scrolls to the Location section to find the physical address (Victoria Island, Lagos), phone number, email, and opening hours.

  • Wishlist, toast notifications, responsive design
  • Brand story, newsletter, location section
  • Technical + product documentation
→ Next — v1.1
Enhanced Prototype
  • Real product photography
  • Category filtering on product grid

  • Cart persisted in localStorage
  • Mobile nav hamburger menu
↗ Future — v2.0
Live Production Site

  • SMS/email order notifications
  • Delivery tracking integration
