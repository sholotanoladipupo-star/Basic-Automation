Lagos Luxe — Website Technical Reference

Complete technical documentation covering architecture, code structure, component design, and implementation details for the Lagos Luxe e-commerce fashion website.

Version 1.0.0 Date June 2025 Type Single-File HTML App Author Lagos Luxe Dev Team

📋 1. Project Overview

The Lagos Luxe website is a single-file, self-contained front-end web application built entirely with HTML, CSS, and vanilla JavaScript. It is designed as a fully functional, presentation-ready e-commerce storefront for a premium Nigerian clothing brand — requiring zero build tools, zero frameworks, and zero installation.

The site can be opened directly in any modern web browser by double-clicking the index.html file. No server, no npm, no dependencies.

💡
Design Philosophy: Every feature was implemented using native browser capabilities. The cart, product rendering, and UI interactions are all vanilla JavaScript — demonstrating the power of the platform without adding framework complexity.

Core Capabilities

Product Catalog Shopping Cart Wishlist Toggle Responsive Design CSS Animations Toast Notifications Dynamic Rendering Cart Sidebar No Dependencies Offline Ready

🎯 6. CSS Custom Properties (Design Tokens)

All colors and key visual values are defined as CSS custom properties on the :root selector. This makes global theme changes trivial — modify one value, update everywhere.

:root {
  --navy:       #0D1B2A;     /* Primary dark — navbar, headings, buttons */
  --navy-light: #1A3352;     /* Hero gradient mid-stop */
  --gold:       #C9A84C;     /* Brand accent — logo, badges, highlights */
  --gold-light: #E8C96A;     /* Gold hover/active state */
  --gold-pale:  rgba(201,168,76,0.12); /* Subtle gold tint for backgrounds */
  --white:      #FFFFFF;     /* General backgrounds */
  --gray:       #F4F5F7;     /* Section backgrounds (alternating) */
  --border:     #E4E4E4;     /* Card borders, table lines, dividers */
  --text:       #1A1A1A;     /* Body text */
  --muted:      #777777;     /* Secondary/helper text */
}
💡
To retheme the entire website (e.g., switch from gold to emerald), update --gold and --gold-light in the :root block. All 50+ uses update automatically.

🛒 8. Cart System — Deep Dive

The cart is a client-side, in-memory state management system. Cart data persists only for the current browser session (not localStorage).

Cart Data Structure

// Each cart item is a product object + qty field
let cart = [
  {
    id: 1,
    name: 'Classic Oxford Shirt',
    category: "Men's Shirts",
    price: 12500,
    qty: 2            // ← qty added on top of product fields
  },
  // ...
];

Cart Functions

addToCart(id) State Mutation
Looks up product by id from the products array. If item already in cart, increments qty. Otherwise, spreads product into a new cart item with qty: 1. Calls updateCartUI() and openCart(). Also triggers button feedback (green "✓ Added" state) and badge bump animation.
changeQty(id, delta) State Mutation
Finds item in cart and applies delta (+1 or -1) to its qty. If qty reaches 0 or below, calls removeFromCart() instead of keeping zero-qty items. Calls updateCartUI().
updateCartUI() DOM Update
The central UI synchronization function. Recalculates total price and item count. Updates the cart badge number in the navbar. Conditionally renders either the empty-cart state or a list of cart items. Shows/hides the cart footer with total and checkout button.
openCart() / closeCart() DOM Update
Toggles the .open CSS class on #cartSidebar and #overlay. CSS transitions handle the slide-in animation (right: -420px → 0). Also toggles document.body.style.overflow to prevent background scroll when cart is open.

Cart Flow Diagram

User clicks "Add" button
        ↓
  addToCart(productId)
        ↓
  Find product in products[]
        ↓
  Item in cart? ──YES──→ item.qty++
        │                    ↓
       NO             updateCartUI()
        ↓                    ↓
  Push {…product, qty:1}  openCart()
  to cart[]
        ↓
  updateCartUI()
        ↓
  openCart() + button feedback + badge bump

🎴 9. Product Rendering Engine

Products are defined as a JavaScript array of objects. The renderProducts() function maps this array to HTML template strings and injects them into #productsGrid via .innerHTML.

Product Object Schema

// Each product in the products[] array:
{
  id:        Number,    // Unique identifier (used as DOM key)
  name:      String,    // Display name
  category:  String,    // Category label shown above product name
  desc:      String,    // Short description text
  price:     Number,    // Current price in Naira (no ₦ symbol in data)
  oldPrice:  Number|null, // Original price (shown crossed out if set)
  badge:     String|null, // "sale" | "new" | "premium" | null
  gradient:  String,    // CSS gradient string for product image background
  icon:      String,    // Emoji used as product visual
}

HTML Generation Pattern

function renderProducts() {
  const grid = document.getElementById('productsGrid');

  // Array.map() → template literals → .join('') → .innerHTML
  grid.innerHTML = products.map(p => `
    <div class="product-card">
      <div class="product-img-wrap" style="background: ${p.gradient};">
        ${p.badge ? `<span class="badge-${p.badge}">...</span>` : ''}
        <!-- wishlist button, icon emoji -->
      </div>
      <div class="product-info">
        <!-- category, name, desc, price, add button -->
      </div>
    </div>
  `).join('');
}
ℹ️
Adding new products: Simply add a new object to the products[] array. The grid will automatically include it on next page load. No other changes required.

▶️ 13. How to Run

Option A — Direct File Open (Simplest)

# macOS / Linux
open "FIRST CLOTHING WEBSITE/index.html"

# Windows
start "" "FIRST CLOTHING WEBSITE\index.html"

# Or: Right-click index.html → Open With → Your Browser

Option B — Local Development Server

# Using Python (built-in on macOS/Linux)
cd "FIRST CLOTHING WEBSITE"
python3 -m http.server 8080
# Then open: http://localhost:8080

# Using Node.js (npx)
npx serve "FIRST CLOTHING WEBSITE"
# Then open the URL printed in terminal

# Using VS Code
# Install "Live Server" extension → Right-click index.html → "Open with Live Server"
💡
For a quick presentation demo, Option A (direct file open) is all you need. The website is fully functional without any server.

Adding LocalStorage Persistence to Cart

// After updateCartUI(), add:
localStorage.setItem('lagosLuxeCart', JSON.stringify(cart));

// On page load (before renderProducts()), add:
const saved = localStorage.getItem('lagosLuxeCart');
if (saved) { cart = JSON.parse(saved); updateCartUI(); }
